# Time to Graze — дизайн-документ

Мод для RimWorld 1.6 (Unity/Mono) и 1.7 (Waylith/.NET 10). Расширяет животноводство: животновод выводит голодное стадо из загона на пастбище, сторожит и возвращает обратно.

## Решения брифинга (2026-11-04)

| Тема | Решение |
|---|---|
| Куда выводят | Новая зона **«Пастбище»** (Zone, меню «Зоны»). К загону привязывается одно или несколько пастбищ |
| Как ведут | Ванильные **верёвки** (как `JobDriver_RopeToDestination`): берёт группу, ведёт, отпускает |
| Запуск | Сытость < X% (любое животное / доля стада) · окно по часам · корма в загоне < N дней |
| Возврат | Все наелись ≥ Y% · конец окна или ночь · опасность (рейд, хищник/манхантер рядом, токсичные осадки, экстремальная температура) |
| Кто ведёт | Любой колонист с работой «Животные» (WorkGiver в Handling); назначенный на загоне пастух в приоритете |
| Пастух | Стоит на страже всё время выпаса (занят), ловит разбредающихся, получает опыт «Животных» |
| Собака | Новая дрессировка **«Пастьба»** (нужно «Послушание»); доступна собакам и собакоподобным, моддеры подключают через XML |
| Фильтр стада | Все, кто ест траву; галочки «без больных/раненых», «без беременных», «без молодняка»; ручное исключение |
| Мультиплеер | Не сейчас; код детерминированный (`Rand`, не `System.Random`) |
| Сборка | Исходники здесь (git), скрипт кладёт мод в `Steam\…\RimWorld\Mods\TimeToGraze`; RU + EN |

## Баланс по умолчанию (всё в настройках мода)

Множители шанса разбредания на пастбище (ванильный шанс вне загона = 1.0):

| Охрана | Разбредание | Атака хищника |
|---|---|---|
| никого | ×0.5 | ×1.0 |
| собака | ×0.25 | ×0.6 |
| пастух | ×0.15 | ×0.5 |
| пастух + собака | ×0.05 | ×0.3 |

Эффект пастуха масштабируется навыком «Животные».

## Дополнительно

- Собака/пастух отгоняют хищника, если тот всё же подошёл; стадо сбивается к охране; оповещение.
- Мысль пастуха «Спокойный день на пастбище» (+настроение, сильнее у любителей природы) и опыт «Животных» за смену.
- Ротация пастбищ: выбирается привязанное пастбище с наибольшим запасом травы.
- Оверлей привязанных пастбищ при выборе метки; в вкладке — запас травы в днях, статус стада, кто сторожит.

## UI: вкладка «Выпас» на метке загона

Новый `ITab` рядом с ванильными `ITab_PenAnimals` / `ITab_PenFood` / `ITab_PenAutoCut`:
вкл/выкл, привязанные пастбища, условия запуска/возврата, окно по часам, пастух (выбор колониста), собака (выбор животного), фильтр стада, кнопка «Выгнать сейчас / Вернуть сейчас», статус.

## Реализация (как сделано)

- Удержание на пастбище — Harmony-постфикс на `Pawn_PlayerSettings.EffectiveAreaRestrictionInPawnCurrentMap`: пасущемуся животному подставляется скрытая область `Area_Pasture`, зеркало зоны. Поиск еды, блуждание и пути её уважают без доп. патчей.
- В 1.6/1.7 поиск путей знает только области из `AreaManager.AllAreas`, поэтому `Area_Pasture` регистрируется там на время выпаса (невыбираемая, не видна в UI) и вырезается из сохранения патчем `AreaManager.ExposeData` — сейвы не зависят от мода.
- Ванильные животные едят только проголодавшись (останавливаются на ~50–80%), поэтому в дерево мышления (`Animal_PreWander`) вставлен `JobGiver_GrazeAtPasture`: на выпасе стадо щиплет траву до порога «наелись».
- Собака — `JobGiver_GuardHerd` в том же месте дерева; «Пастьба» подключается к породам через `race/trainableTags` (`TTG_Herding`), работает без Odyssey.
- Пастбище скрывается как ванильные зоны (`Command_Hide_ZonePasture`; ПКМ — показать/скрыть все зоны или все пастбища).
- Вкладка и окно настроек рисуются `Listing_Standard` с `maxOneColumn = true`: без этого содержимое выше прошлого кадра уезжало в невидимую колонку, и вкладка становилась пустой.
- Ванильные «отвести в загон» блокируются для пасущихся (кроме фазы возврата и ушедших в разбредание).

## Сборка

```
powershell -ExecutionPolicy Bypass -File build.ps1            # собрать 1.6 + 1.7 и установить в RimWorld/Mods/TimeToGraze
powershell -ExecutionPolicy Bypass -File build.ps1 -NoDeploy  # только собрать
```

Проверено в RimWorld 1.7.4998 (автотест в отдельном профиле): вывод на верёвках → выпас с пастухом и собакой → сохранение/загрузка посреди выпаса → возврат по «все наелись» и по опасности (хищник), вкладка и переводы. Сборка 1.6 компилируется против `Krafs.Rimworld.Ref 1.6.4871`, в игре 1.6 не запускалась.

## Техника

- Сборка: `net472` + `Krafs.Rimworld.Ref 1.6.*` + Harmony 2.x → `1.6/Assemblies`; `net10.0` + `Krafs.Rimworld.Ref 1.7.*-*` + Harmony 3.0 → `1.7/Assemblies`. Общий исходник, общие `Defs`/`Languages` в корне.
- Точки вмешательства (Harmony):
  - `ThinkNode_ChancePerDay_Roam` / `JobGiver_StartRoaming` — множитель шанса разбредания для пасущихся.
  - Ванильные работы «отвести в загон незапертых животных» (`JobDriver_RopeRoamerToUnenclosedPen` и др.) — не трогать пасущихся, пока выпас активен.
  - Выбор жертвы хищником (`FoodUtility.BestPawnToHuntForPredator`) — множитель для охраняемого стада.
- Состояние выпаса — `MapComponent` (+ `ThingComp` на метке загона), сохраняется в сейв.
- Harmony 3 строже проверяет типы `__instance`/`__result` — патчи писать с точными типами.
